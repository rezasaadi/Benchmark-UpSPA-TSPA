# Active benchmark crate

Build and run this crate through the repository-root scripts. The root [README](../README.md) lists Linux build, test, local, namespace, LAN, WAN, grid, and summary commands.

`bench_unified` measures local computation or actual TCP end-to-end execution. `network-node` hosts one storage provider or the ordinary login server. Historical analytical latency and server-cost injection are absent from the active benchmark.
